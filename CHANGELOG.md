# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-06

### Added

- Floating window hosting the official DeepSeek web chat (`chat.deepseek.com`) inside DeepSeek Harness desktop.
- Sidebar footer entry, slide-in/slide-out motion, drag, resize, right-edge following, and content-area maximize with a labelled restore control.
- Remembered sign-in: the site's local storage is snapshotted locally after login and restored on the next open or app restart.
- Isolated embedded page: sandboxed webview without Node or preload access to the harness.
- Simplified Chinese and English UI copy.
- GitHub-ready repository files: README, MIT license, contributing and security guides, changelog, CI, and issue template.
